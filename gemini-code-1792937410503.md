# 🍷 Cata de Vinos Personalizada

Aplicación web interactiva y ligera diseñada para organizar, registrar y puntuar catas de vino en un entorno cercano (ideal para planes con amigos o familia). 

## ✨ Características
- **Fichas de cata interactivas:** Registro detallado de fase visual, olfativa, gustativa y puntuación global.
- **Maridaje y recomendaciones:** Guía rápida de acompañamiento para potenciar la experiencia.
- **Ranking de favoritos:** Visualización dinámica de las valoraciones de los participantes.
- **100% Responsive:** Diseñada para consultarse cómodamente desde cualquier smartphone durante la cata.

## 🚀 Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla)
